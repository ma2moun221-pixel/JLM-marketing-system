# قوالب جاهزة حسب نوع الفيديو

ابدأ من القالب الأقرب ثم عدّل. الغرض توفير قرارات لا سؤال المستخدم عنها.

## 1) ريلز تسويقي لمنتج (25–35s)

```json
{
  "aspect": "9:16", "crop_mode": "blur", "fps": 30,
  "color": {"contrast": 1.08, "saturation": 1.12, "brightness": 0.02},
  "audio": {"normalize": true, "target_lufs": -14},
  "music": {"gain_db": -20, "ducking": true},
  "quality": {"crf": 18, "preset": "medium"}
}
```

- سرعة المقاطع `1.08`، `zoom` متبادل بين `1.0` و`1.08`.
- كابشن: `hook` واحد + 4–6 `body` + `cta` واحد في النهاية.
- أيقونات: 3–4 عبر الفيديو، `size` 0.15.
- **الهوك:** نتيجة أو رقم قبل ذكر المنتج إطلاقًا.

## 2) شرح تعليمي / تيوتوريال (40–60s)

```json
{
  "aspect": "9:16", "crop_mode": "crop", "fps": 30,
  "color": {"contrast": 1.05, "saturation": 1.05, "brightness": 0.02, "sharpen": true},
  "audio": {"normalize": true, "target_lufs": -14},
  "music": {"gain_db": -24, "ducking": true}
}
```

- سرعة `1.0` — التسريع يُفقد الفهم في المحتوى التعليمي.
- كابشن `body` مستمر بلا انقطاع (المشاهد يتابع بلا صوت).
- أيقونات ترقيم الخطوات: 1️⃣ 2️⃣ 3️⃣ في `top-left`.
- موسيقى منخفضة جدًا أو بلا موسيقى.

## 3) شهادة عميل (15–25s)

```json
{
  "aspect": "9:16", "crop_mode": "crop", "fps": 30,
  "color": {"contrast": 1.06, "saturation": 1.06, "brightness": 0.03},
  "audio": {"normalize": true, "target_lufs": -14},
  "music": {"gain_db": -26, "ducking": true}
}
```

- احذف كل تردّد وصمت (`--min-silence 0.3`).
- سرعة `1.05` كحد أقصى — التسريع يُفقد المصداقية.
- كابشن حرفي لكلام العميل، `body`.
- **بلا** أيقونات — تُضعف المصداقية في الشهادات.
- اسم العميل + صفته بنمط `sub` في أول 3 ثوانٍ.

## 4) إعلان مدفوع (15–20s)

```json
{
  "aspect": "4:5", "crop_mode": "blur", "fps": 30,
  "color": {"contrast": 1.10, "saturation": 1.15, "brightness": 0.03},
  "audio": {"normalize": true, "target_lufs": -14},
  "music": {"gain_db": -18, "ducking": true},
  "quality": {"crf": 17, "preset": "slow"}
}
```

- إيقاع سريع: قطع كل 1.5s، سرعة `1.10`.
- المنتج مرئي في أول ثانيتين.
- `cta` واضح في آخر 3 ثوانٍ.
- 4:5 يأخذ مساحة أكبر في الـ Feed من المربّع.
- انتبه للمناطق الآمنة — نص الإعلان المقصوص يُرفض أحيانًا.

## 5) قبل/بعد (10–15s)

```json
{
  "aspect": "9:16", "crop_mode": "crop", "fps": 30,
  "color": {"contrast": 1.08, "saturation": 1.10, "brightness": 0.02},
  "music": {"gain_db": -14, "ducking": false}
}
```

- مقطعان فقط: «قبل» ثم «بعد»، بلا تعليق صوتي غالبًا.
- كابشن `center` كبير: «قبل» / «بعد».
- موسيقى أعلى (لا كلام) مع `ducking: false`.
- ✅ إيموجي على مقطع «بعد».

## 6) يوتيوب أفقي (60s+)

```json
{
  "aspect": "16:9", "crop_mode": "pad", "fps": 30,
  "color": {"contrast": 1.05, "saturation": 1.05, "brightness": 0.01},
  "audio": {"normalize": true, "target_lufs": -14},
  "quality": {"crf": 18, "preset": "slow", "audio_bitrate": "192k"}
}
```

- إيقاع أهدأ: قطع كل 4–6 ثوانٍ.
- كابشن `sub` للنقاط المهمة فقط، لا كابشن مستمر.
- المنطقة الآمنة أوسع بكثير من العمودي.
