# JLM «العناية الدورية» — المونتاج

## النسخة الثالثة (الحالية): أسلوب «DPF Cleaner» الجديد، `out/jlm_care_edit_v3.mp4`
المدة 24.9 ث، وتُثبَّت آخر لقطة 1 ث. الصوت ‎-14.3 LUFS، والذروة ‎-2.7 dBFS.
الأسلوب موثّق في `brand/jlm/VIDEO_STYLE.md`، والسكربت `scripts/edit_v3.py`.
- **الكابشن:** سطر واحد عند 66% من الارتفاع، فوق صندوق داكن ناعم. الكلمة المنطوقة صفراء، وما بعدها رمادي.
  - كلمات المشكلة حمراء: المرض، العطل، أعطال.
  - الكلمات الأساسية صفراء ثابتة.
- **الشارات:** أقراص داكنة في الزاويتين العلويتين، حلقتها وأيقونتها الخطّية ترسمان نفسيهما، وتحتها وسم صغير:
  - قلب «صحّتك أولًا» (أحمر).
  - سيارة مع «!» «لا تنتظر العطل» (أحمر).
  - تقويم «عناية دورية».
  - سيارة مع ✓ «اهتم اليوم».
  - عملات «وفّر بكرا».
  - درع مع قطرة «حماية من الداخل».
- **وسم المنتج:** «منتجات JLM للعناية الدورية» في أعلى الوسط أثناء صبّ المنتج.
- **الشرح المتحرك (11.1–16.4):** لوحة داكنة، ومسار ذهبي، وكاميرا تنزل مع ثلاث خطوات مرقّمة:
  1. نظافة المحرّك.
  2. نظام الوقود.
  3. أداء السيارة.
- **الختام:** شعار JLM الأصلي في الأعلى، وحبة صفراء «jlmstore.com» تحت الكابشن.
- **الأصوات:** «تِك» ناعم جدًا عند كل شارة، عند ≈ ‎-40 dBFS، أي أهدأ بنحو 10 dB من v2.

```bash
python3 scripts/edit_v3.py --src CLIENT_VIDEO.mp4 --out out/jlm_care_edit_v3.mp4          # ~1.5 دقيقة
python3 scripts/edit_v3.py --src CLIENT_VIDEO.mp4 --out out/x.mp4 --stills 2,12,15,22   # صور فحص
```

## النسخة الثانية (رفضها العميل): أسلوب المتحدّث، `out/jlm_care_edit_v2.mp4`
المدة 25.4 ث، منها 1.5 ث بطاقة الختام. الأسلوب موثّق في `brand/jlm/VIDEO_STYLE.md`، والسكربت `scripts/edit_v2.py`.
- **الكابشن:** كلمة بكلمة على الصدر، بلا صندوق.
  - السطر العادي أبيض، والكلمة المفتاحية صفراء وأكبر تحته.
  - الخط Helvetica Neue LT Arabic Bold، والأرقام Albert Sans Black.
- **النقاط الثلاث:** «1 نظافة المحرّك»، «2 نظام الوقود»، «3 أداء السيارة».
  - تبني فوق الرأس صفًا من ثلاث أيقونات: محرّك ← مضخة وقود ← عدّاد.
- **الأيقونات:** مربعات بإطار أصفر متقطّع، ثابتة بلا حركة داخلية.
  - مكانها فوق الرأس أو بجانب الوجه حسب مسار الوجه في كل لقطة، ولا تغطّي الوجه أبدًا.
- **لقطة الإدراج:** واحدة فقط، 1.5 ث، تُظهر الرواسب وهي تتفتّت (12.45–13.95).
- **الأصوات:** نقرات ناعمة (520Hz، حوالي ‎-30dB) وخلفية موسيقية هادئة جدًا تحت الصوت.
- **الختام:** تعتيم مع شعار JLM و jlmstore.com وزر «اطلبه الآن».
